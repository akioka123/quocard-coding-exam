# 想定処理

## 著者登録

1. 著者を登録する。（すべてのスタート地点はここ）
2. まず初めに著者が登録されるものとする。
3. 著者登録時に登録済みの書籍（著作）は同時に登録できるものとする。
4. 書籍の新規登録はできない。

## 書籍登録

1. 書籍を登録する。
2. 登録されている著者から選択されたものが同時に登録できる。
3. 同時に著者の登録はできない。

## 書籍取得

1. 選択した著者に関連する書籍情報の一覧を返却する。

## 著者更新

1. 選択した著者情報を更新する。
2. 書籍に関しては選択した書籍に更新する。（Delete+Insertの考え方とする）
3. 書籍情報の更新はできない。
4. 更新時に対象の著者に関連する書籍IDを洗い替えする。

## 書籍更新

1. 選択した書籍情報を更新する。
2. 著者に関しては選択した著者に更新する。（Delete+Insertの考え方とする）
3. 著者情報の更新はできない。
4. 更新時に対象の書籍に関連する著作IDを洗い替えする。
